BILDAD CHIEDOZIE — DEVELOPER PORTFOLIO

FILES
- index.html  Page content and semantic structure
- style.css   Responsive dark UI styling and animations
- script.js   Mobile navigation, project filters, reveal effects, copy buttons,
              current year, and contact-form mailto behavior

RUN IT
1. Extract the folder.
2. Open index.html in a modern browser. No build tools or framework are required.
3. For local development, you can use VS Code + Live Server, or open the file directly.

IMPORTANT BEFORE PUBLISHING
1. Open script.js and replace CONTACT_EMAIL = 'YOUR_EMAIL@example.com' with your real email.
   The contact form prepares a message in the visitor's email app; it does not send data
   to a server. A real backend or form service would be needed for server-side submissions.
2. Review all personal details and project descriptions so they accurately reflect your work.
3. Project cards are explicitly labelled as concepts / in progress; add GitHub/demo links when ready.
4. Google Fonts are loaded from the internet; fallback fonts are provided if unavailable.

FUNCTIONS INCLUDED
- Responsive navigation menu with keyboard Escape support
- Active section navigation highlighting
- Scroll reveal effects, with reduced-motion preference support
- Project category filtering (All / Web / Concepts)
- Copy terminal command and email buttons
- Contact form validation and mailto draft generation
- Automatic copyright year

DESIGN NOTES
Inspired by the supplied “Obsidian Kinetic” design reference: near-black surfaces, electric violet
and cyan accents, restrained glass-like panels, Plus Jakarta Sans headings, Inter body text, and
JetBrains Mono metadata. Content has been adapted for Bildad's student/developer-in-progress profile
rather than copying the fictional claims and sample projects from the reference.
